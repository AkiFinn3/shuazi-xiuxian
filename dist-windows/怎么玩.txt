谁让这个刷子修仙的 · Windows 版
================================

怎么玩
------
1. 把整个文件夹解压到任意目录（路径尽量别用中文，避免个别系统脚本出错）。
2. 双击「Start Game.bat」。
3. 会自动弹出一个本地服务，并打开浏览器进入游戏。
   如果浏览器没自动打开，手动访问 http://127.0.0.1:8231/index.html
4. 玩的时候别关那个小黑窗口（那是游戏服务器）。

说明
----
* 不用安装任何东西：本地服务用的是 Windows 自带的 PowerShell。
* 第一次运行可能会被 Windows 防火墙拦一下，选择「允许访问」即可（只监听 127.0.0.1，不对外网开放）。
* 存档保存在浏览器本地。换电脑玩：游戏内「设置 - 导出存档」复制存档码，在新电脑「导入存档」。
* 想在手机上玩：同一 Wi-Fi 下，用手机浏览器访问这台电脑的局域网 IP + 8231 端口。
* 卸载：直接删掉这个文件夹即可（记得先导出存档码）。
